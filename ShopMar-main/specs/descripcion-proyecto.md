# shpr — Descripción del proyecto

`shpr` es una plataforma web de gestión para una tienda de ropa de segunda mano (paca) operada por una sola persona, construida para reemplazar las planillas de cálculo con las que hoy se registran ventas, paquetes y gastos. El panel se abre con una cuenta y una contraseña —usuario o correo— y hay dos roles: vendedor y administrador (solo el administrador da de alta usuarios). La sesión no vence: solo se cierra al hacer logout, para que la dueña y sus empleados usen el panel desde el teléfono sin volver a escribir credenciales. La API REST exige esa sesión y sigue operando en un entorno privado, así que la perimeterización del host se suma a la autenticación (`modules/api/07-auth.md`, D-024). Toda la información de negocio se persiste en PostgreSQL a través de Drizzle, con importes monetarios exactos en `DECIMAL(10,2)`, borrado lógico en lugar de eliminación física, y una regla de negocio central: el total de una venta nunca se almacena desnormalizado, se deriva siempre como `sale.cost + SUM(additional_sale.total)`. El frontend es una aplicación Astro 7 de compilación estática, sin frameworks ni bibliotecas de interfaz, que consume la API en tiempo de ejecución desde el navegador y presenta un panel administrativo de estilo minimal light con el panel completo: resumen de indicadores, ventas con factura imprimible, alta de venta de mostrador y de WhatsApp, paquetes, gastos, clientes y el selector de registro, más la pantalla de inicio de sesión.
